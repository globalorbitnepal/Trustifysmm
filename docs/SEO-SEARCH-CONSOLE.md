# Google Search Console readiness

Production host: `https://trustifysmm.com` (the `www` host 308-redirects to it, so only one
hostname is ever indexed).

## 1. Verify domain ownership

Two supported methods. Do not paste a token you have not generated yourself.

**DNS TXT (recommended — covers apex, www and every subdomain)**

1. Open Search Console → *Add property* → **Domain** → enter `trustifysmm.com`.
2. Copy the `google-site-verification=…` TXT value Search Console gives you.
3. Add it as a TXT record at your DNS provider (`@` / apex).
4. Return to Search Console and click **Verify**.

**HTML tag / file (only for a single URL prefix)**

Set the environment variable `GOOGLE_SITE_VERIFICATION` to the token value from the HTML tag
method. `app/layout.tsx` reads it and emits `<meta name="google-site-verification">` — no token
is hard-coded in the repository. Rebuild and redeploy after adding it.

Alternatively place the downloaded `google<token>.html` file in `public/`.

## 2. Submit the sitemap

`https://trustifysmm.com/sitemap.xml`

- Generated by `app/sitemap.ts` from the live catalogue, the SEO landing registry and the
  published blog list.
- Private routes, noindexed pages, drafts, duplicate URLs and query strings are excluded.
- `lastmod` comes from real file modification times or the post's `updatedAt` — never invented.

## 3. Verify robots.txt

`https://trustifysmm.com/robots.txt`

- `Allow: /` with the private app areas disallowed (`/orbit`, `/dashboard`, `/api/`,
  `/account`, `/checkout`, `/payment`, `/wallet`, password reset routes).
- `Sitemap:` line points at the canonical sitemap.
- `/signin` and `/signup` are *not* disallowed: they carry a `noindex` meta tag instead, which a
  crawler can only read if it is allowed to fetch the page.

## 4. Checks before requesting indexing

| Check | Expected |
| --- | --- |
| Sitemap returns 200 with `application/xml` | yes |
| robots.txt returns 200 | yes |
| Public pages return 200 | yes |
| `www` returns 308 to apex | yes |
| Canonicals are absolute and self-referencing | yes |
| `/dashboard` and `/orbit` redirect to auth | 307 |
| Private responses carry `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet` | yes |
| Rendered HTML contains title, description, canonical, OG, Twitter, JSON-LD | yes |

Run the automated check any time:

```bash
npm test            # includes tests/seo-landing.test.ts
npm run build       # fails if any metadata module breaks
```

## 5. After submission

- Use **URL Inspection** per landing page to confirm Google fetched the canonical.
- Watch **Pages → Not indexed → Excluded by noindex tag** — that list should contain only auth and
  private routes.
- Indexing cannot be forced or guaranteed. This document records readiness, not a ranking result.
